# 🖼️ Pengolahan Citra Digital

Aplikasi desktop untuk pengolahan citra digital yang dibangun menggunakan Python, PySide6, dan OpenCV. Program ini bersifat edukatif untuk mata kuliah Pengolahan Citra.

## ✨ Fitur

- **15 Metode Pengolahan Citra:**
  - Transformasi Titik Piksel: Thresholding, Grayscale, Negative, Brightness, Contrast
  - Filtering & Konvolusi: Noise, Edge Detection, Equalization, Emboss, Sharpening, Smoothing, Convolution
  - Transformasi Geometrik: Mirroring, Rotation
- **Webcam Real-Time:** Pengolahan citra langsung dari webcam
- **Histogram Real-Time:** Visualisasi distribusi piksel secara langsung
- **Antarmuka Intuitif:** Panel input dinamis yang berubah sesuai metode

## 🛠️ Teknologi

- Python 3.10+
- PySide6 (Qt for Python)
- OpenCV
- NumPy
- Matplotlib
